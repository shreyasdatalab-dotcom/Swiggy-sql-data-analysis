# Swiggy SQL Data Analysis Project

## 📌 Project Overview

This project analyzes Swiggy restaurant and menu data using MySQL. The objective is to explore restaurant ratings, cuisine trends, menu categories, and pricing patterns to answer business-related questions.

## 🎯 Project Objectives

- Identify highly rated restaurants.
- Find cities with the highest number of restaurants.
- Analyze popular cuisines and city-wise ratings.
- Explore menu categories and item pricing.
- Analyze vegetarian and non-vegetarian menu offerings.
- Rank restaurants by rating within each city.

## 🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL

## 📊 Dataset Information

The dataset contains restaurant and menu information, including:

- Restaurant name and city
- Restaurant rating
- Cuisine and menu category
- Menu item and price
- Cost per person
- Vegetarian/non-vegetarian classification

## 🧠 SQL Concepts Practiced

- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- DISTINCT and LIKE
- Subqueries
- JOINs
- Common Table Expressions (CTEs)
- CASE statements
- Window functions using DENSE_RANK()

## ❓ Business Questions

1. How many restaurants have ratings above 4.5?
2. Which city has the highest number of restaurants?
3. Which cuisines are most common?
4. What is the average restaurant rating in each city?
5. Which restaurants offer the most menu items?
6. Which cities are the most and least expensive for dining?
7. Which restaurants are 100% vegetarian?
8. Which restaurants rank highest within their cities?
